Model-agnostic agent infrastructure

Build agents you can inspect, compose, and replace.

AgentForge is a typed runtime, workflow engine, CLI, and visual control plane for production-minded AI systems.

Quick start

pnpm install
pnpm build
pnpm --filter @agentforge/examples basic
pnpm --filter @agentforge/playground dev

Architecture

SDK / CLI / Playground→Agent runtime→Models + tools→Events + storage

Provider-specific code remains inside adapters. Runtime contracts live in @agentforge/core; the convenience facade is @agentforge/sdk.

Agents & tools

const agent = new Agent({
  name: 'researcher',
  model: createModel({ provider: 'mock' }),
  tools: [webSearchTool],
  maxIterations: 8,
});

const result = await agent.run('Research typed agent runtimes.');

Security

Keep restricted tools opt-in, use host and command allowlists, validate all structured values, enforce timeouts, and redact secrets before events are persisted.
